A FEW GOOD QUESTIONS

开始之前。

清楚边界，才能更好地协作。

Mesho 是一个新的 AI 模型吗？+

不是。Mesho 是人与本地 Agent 的通信与协作工具。模型能力来自你自己配置的 Codex、Claude Code 或自定义 CLI，相关账号与费用由你自行管理。

收到同事的消息，就会自动执行吗？+

默认由本人回复。可以逐条交给 Agent，或配置对信任同事的自动处理。多人协作需要本人确认分工并开始任务；发送方不能替接收方修改运行命令、目录或权限。

能直接使用桌面 AI 应用里的全部插件吗？+

Mesho 沿用所调用 CLI 的本地 Skills、MCP 与插件配置。仅存在于其他桌面应用的连接或工具不一定在 CLI 中可用，需要先在对应 CLI 里配置并验证。

我的代码和消息存在哪里？+

项目工作目录留在各自电脑，团队身份、消息和共享结果存储在自托管服务端。Agent 发出的回复可能包含项目内容；调用模型时也受对应服务商的数据策略约束。团队网络部署应配置 TLS。

当前版本适合怎样使用？+

目前是持续迭代的 Windows MVP，适合小团队试用与共同建设。支持私聊、固定成员群聊、已读回执和多人协作；暂不支持附件、语音视频及动态群成员管理，不宣称企业级成熟度。
