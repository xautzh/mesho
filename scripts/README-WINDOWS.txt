Mesho 0.5.1 · Windows 快速开始

1. 启动服务端，再启动客户端。原有身份与聊天记录保存在本机数据目录。
2. 在通讯录点击「发消息」，或在消息页新建群聊。直接输入 @ 选择成员。
3. 每个人在设置中选择收到消息后如何处理：自己回复、Agent 处理前确认、信任同事自动处理。
4. 使用 Agent 时，选择本机工作目录、执行器和回复方式。无需与发送方约定项目 ID。
5. Agent 回复可自动发送，也可在任务详情确认后发送。失败任务在本地查看。
6. 窗口关闭后仍留在系统托盘；切换版本前请从托盘退出客户端。

默认数据目录：%APPDATA%\Mesho
第二个客户端可通过 MESHO_DATA_DIR 设置独立数据目录。
服务端数据：server\mesho.db
邀请码：server\server.local.json

消息支持 Markdown 表格与代码块。私聊显示已读，群聊显示已读人数；Agent 处理状态随消息同步。升级后需同时重启服务端与客户端。

持续协作：聊天右上角点击“发起协作”，填写目标与验收标准。自己的 Agent 可在执行中询问同事，收到关联答复后续接原会话。接收方可人工回答或按自己的配置交给 Agent。最终结果由发起人验收发布；可随时停止或补充要求。
